# Code of Conduct

MIDAS is intended to be a practical, respectful developer community.

## Expected Behavior

- Be direct, kind, and specific.
- Critique code and ideas, not people.
- Respect maintainer boundaries around security reports, release claims, and license review.
- Do not post secrets, private data, customer data, or proprietary material.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Publishing private vulnerability details before maintainers can respond.
- Submitting copied material without clear license permission.
- Using project spaces to pressure maintainers into public claims, deployments, or releases.

Maintainers may remove comments, close issues, or restrict participation to keep the project usable and safe.
