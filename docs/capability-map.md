# MIDAS Capability Map

Status: alpha public map

| Capability | Current MIDAS status | Next implementation |
|---|---|---|
| Installer and onboarding | Alpha CLI: `install`, `update`, `doctor`, `validate`. | Add update channels and pinned manifest refresh. |
| Work-order system | `midas quick` creates scoped work orders. `midas run-workflow` creates workflow work orders. | Add depth bands and acceptance-criteria prompts. |
| Local planning | `midas plan` creates PRD, DESIGN, EXPERIENCE, and handoff files under `.midas/planning/`. | Add optional local-model interactive adapters. |
| Agent profiles | Machine-readable planner, builder, reviewer, and researcher profiles with semantic permission checks. | Add tool-specific renderers for richer native harness profile config. |
| Authority contracts | Generated `.midas/authority/constitution.json` plus `midas authority` validation for authority order, protected invariants, conflict policy, verification-before-done rules, escalation rules, and claim ceilings. | Add receipt/export hooks that attach authority posture to run summaries. |
| Benchmark receipts | Generated `.midas/benchmarks/receipts.json` plus `midas benchmarks` validation for scorer/version evidence, model route, inference parameters, safe raw/task/item/comparison evidence paths, SHA-256 evidence hashes, score denominator, paired comparison proof for uplift wording, rerun policy, claim level, and public-approval boundaries. | Add run-summary exports that create draft receipts from verified local runs. |
| Skill packs | Generated `.midas/skills/` library plus `midas skills` validation for SKILL.md metadata, trigger descriptions, license fields, compatibility bounds, body size, local references, unsafe allowed-tools hints, and advisory suspicious-body warnings. | Add pack export/import and marketplace-readiness checks. |
| Skill-pack strict validation | `midas validate-pack` validates a single SKILL.md folder or skill library before runtime use. | Add import manifests and dependency validation. |
| UX spine | `midas ux-spine` validates that DESIGN.md components map to EXPERIENCE.md transitions. | Add richer visual-state and route-graph adapters. |
| Verification-gap | `midas verify` writes `.midas/reports/verification-gap-receipt.md` and fails on untraced auditable requirements. | Add AST/tree-sitter adapters beyond token traceability. |
| Docs staleness | `midas docs-staleness` flags source/framework changes that lack matching documentation review. | Add package-level CI hook recipes. |
| Interface quality | Generated `.midas/interface/quality.json` plus `midas interface` validation for UI-facing design context, required evidence gates, safe context paths, contrast, responsive behavior, overflow checks, motion review, keyboard accessibility, screenshot evidence, human review, advisory hook posture, and live-iteration approval. | Add browser-backed proof attachments and optional tool adapters for interface evidence capture. |
| Quality scorecards | Generated `.midas/quality/scorecard.json` plus `midas quality` validation for component scores, required quality dimensions, evidence statements, risks, drift-control posture, approval safety, and public-release claim boundaries. | Add optional evidence attachments and static report export. |
| Flow components | Generated `.midas/flows/components.json` plus `midas flows` validation for typed ports, permission class, promotion stage, approval gates, evidence, rollback, and tool-exposure promotion gates. | Add flow-level graph validation and component proof attachments. |
| Knowledge packs | Generated `.midas/knowledge/packs.json` plus `midas knowledge` validation for allowed source types, citation and license-review requirements, secret/PII exclusions, retrieval tests, quality gates, feedback loops, and app publication gates. | Add retrieval-test evidence attachments and pack import/export. |
| Run controls | Generated `.midas/run-control/policy.json` plus `midas run-controls` validation for bounded scope, sandbox/network posture, subagent packets, message gateway approvals, high-risk approval gates, evidence checkpoints, and closeout requirements. `midas run-workflow --run-control` records the selected profile. | Add check-level proof attachments. |
| Gateway contracts | Generated `.midas/gateways/contracts.json` plus `midas gateways` validation for control-plane entrypoints, authentication, pairing/device identity, schema validation, idempotency, event retention, remote exposure, sandbox binding, diagnostics, approvals, and evidence. | Add runtime-specific gateway renderers and live doctor checks. |
| Channel gateways | Generated `.midas/channels/gateways.json` plus `midas channels` validation for web/chat/scheduler/API/file-transfer surfaces, auth posture, session isolation, file ingress/egress, high-risk tool exposure, cancellation, retention, approvals, and evidence. | Add runtime-specific renderers and channel proof attachments. |
| Workflow engine | `midas run-workflow software-delivery` creates a work order, run-ledger entry, and runtime run state; `midas run-status` reports current step; `midas step` records step evidence and handoffs; `midas observe` records check observations and repair packets; `midas closeout` records result evidence. | Add command execution events and run summary export. |
| Module system | Module manifests validate against `framework/modules/module.schema.json`. | Add pack validation and module dependency rules. |
| Project context | `.midas/project-context.md` and `.midas/context-snapshot.json` generated; `midas context` reports context health, stale snapshots, budget warnings, and manifest/context/tool drift. | Add context section-level refresh helpers. |
| Run ledger | `.midas/run-ledger/` generated; workflow runner creates a started ledger entry; closeout records status, evidence, risks, and next action. | Add run summary export. |
| Runtime run state | `.midas/runtime/runs/<run-id>/run.json` and `events.jsonl` generated; failed observations create bounded repair packets under each run; validator checks runtime, observation, and repair-packet shape. | Add resumable execution and command-output capture. |
| QA/testing | `qa` module plus validator, interface-quality evidence contracts, quality scorecards, tests, and optional workspace project checks through `midas validate --run-checks`. | Add workflow scenario fixtures and UI evidence fixtures. |
| Security/permissions | Public-boundary validator, authority contracts, shared adapter permission policy, semantic agent-profile permission checks, skill allowed-tools checks, and advisory skill-body warnings. | Add JSON reports and rule IDs. |
| Documentation generation | Public templates and bundles. | Add docs pack command. |
| Multi-harness adapters | Codex, Claude Code, Cursor, opencode, Gemini, Copilot outputs with shared permission policy, adapter output contract tests, generated adapter contracts, harness inventory drift checks, and quality-scorecard posture. | Add harness-specific setup notes and marketplace packaging checks. |
| Harness inventory | `midas inventory` checks generated adapter files and hashes against `.midas/harness-inventory.json` and installed manifest tools; `midas context` includes harness inventory health in the broader workspace snapshot. | Add adapter freshness timestamps once update channels exist. |
| Adapter contracts | `midas adapters` validates installed adapter files selected by manifest against machine-readable path, heading, phrase, and size-budget contracts. | Add per-harness optional metadata once public adapter packaging is approved. |
| Cost control | Not implemented. | Track after run ledger exists. |
| Governance/release process | Release plan and public boundary. | Add release checklist command. |
| Community contribution model | Not implemented. | Add contributing and security policy before public launch. |
