# MIDAS Framework v0.1.0-alpha.0

Status: DRAFT. Do not publish as a GitHub Release without explicit approval.
Tag: `v0.1.0-alpha.0`
Commit: `2a28b3de35b128017e7c228e4ad258e63864787d`

MIDAS Framework is an Apache-2.0, dependency-free Node.js CLI for adding project context, scoped work orders, agent guidance, workflow state, and evidence checks to an existing software repository.

## Included in this alpha

- local `.midas/` workspace generation
- project context, work-order templates, run state, and run ledgers
- module, workflow, agent-profile, authority, adapter, and public-boundary validation
- loader-verified guidance paths for Claude Code and Codex
- a dependency-free MCP stdio server for the declared MIDAS tool surface
- contribution, security, conduct, licensing, and release-boundary documentation

## Install from the tag

The package is not published to npm. Clone the pinned source tag:

```bash
git clone --branch v0.1.0-alpha.0 https://github.com/shrishmanglik/MIDAS-Framework.git
cd MIDAS-Framework
npm test
node ./bin/midas.mjs doctor
```

## Known limits

- This is alpha software. Commands and generated file shapes can change between tags.
- There are no known production users.
- Claude Code and Codex adapter loader paths are verified. Cursor, OpenCode, Gemini, and Copilot paths are conventions that remain unverified against those runtimes.
- The repository does not claim production readiness, security certification, autonomous desktop control, or superiority over another framework.
- npm publication and a public launch announcement remain out of scope.
