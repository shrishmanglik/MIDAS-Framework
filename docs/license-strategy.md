# MIDAS License Strategy

Status: recommendation

## Default Recommendation

Use Apache-2.0 for the public MIDAS framework unless final legal/product review chooses a different license.

Reason:

- permissive enough for broad adoption,
- clearer patent grant than MIT,
- better for enterprise adoption,
- supports commercial use while preserving notice and warranty boundaries.

## MIT Alternative

MIT is simpler and familiar. It is a good choice when maximum simplicity matters more than patent clarity.

## Current Alpha Posture

This folder is not publicly released. The package is marked private. The license field records the preferred direction, not a completed publication approval.
