# MIDAS License Strategy

Status: adopted

## Adopted License

Apache-2.0 is the license of the public MIDAS framework. The canonical Apache-2.0
text is at [`LICENSE`](../LICENSE).

Reason:

- permissive enough for broad adoption,
- clearer patent grant than MIT,
- better for enterprise adoption,
- supports commercial use while preserving notice and warranty boundaries.

## MIT Alternative

MIT is simpler and familiar. It is a good choice when maximum simplicity matters more than patent clarity.

## Current Alpha Posture

This repository is public on GitHub under Apache-2.0, as planned in
[`release-plan.md`](../release-plan.md).

The npm package remains marked `private` and is **not** published to the registry, and
there has been no launch announcement. Publishing to npm is a separate decision from
publishing the source.
