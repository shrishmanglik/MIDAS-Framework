# Fabric Database Reference

## Natural Fibers

### Cotton

| Property | Value |
|----------|-------|
| Fiber Source | Cotton plant (Gossypium) seed bolls |
| Common Weaves | Jersey, interlock, pique, poplin, twill, denim, voile, flannel, canvas |
| Weight Range | 80-400 GSM (voile 80-100, shirt 100-150, t-shirt 150-200, sweatshirt 250-350, canvas 300-400) |
| Typical Cost Range | $2.00-$8.00/yard (standard), $6.00-$15.00/yard (organic/premium) |
| Shrinkage | 3-5% (pre-washed/sanforized: <2%) |
| Care | Machine wash warm, tumble dry medium. Can withstand high heat. Prone to wrinkling. |
| Common Uses | T-shirts, shirts, denim jeans, underwear, bed linens, towels |
| Advantages | Breathable, absorbent, soft, hypoallergenic, durable, easy to dye |
| Disadvantages | Wrinkles easily, slower drying, can shrink, absorbs moisture (holds stains), fades in sun |
| Sustainability Note | Conventional cotton is water-intensive (~10,000L per kg). Organic cotton uses less water and no synthetic pesticides. BCI (Better Cotton Initiative) is the most common sustainable standard. |

### Silk

| Property | Value |
|----------|-------|
| Fiber Source | Silkworm (Bombyx mori) cocoon |
| Common Weaves | Charmeuse, crepe de chine, habotai, chiffon, dupioni, organza, taffeta, satin |
| Weight Range | 15-120 GSM (chiffon 15-30, habotai 30-50, crepe de chine 50-80, charmeuse 80-120) |
| Typical Cost Range | $8.00-$30.00/yard (standard), $15.00-$50.00/yard (premium/mulberry) |
| Shrinkage | 3-5% (dry clean recommended to minimize) |
| Care | Dry clean or hand wash cold. No wringing. Iron on low with pressing cloth. |
| Common Uses | Evening wear, blouses, scarves, lingerie, linings, ties |
| Advantages | Luxurious drape and luster, strong for its weight, naturally temperature-regulating, hypoallergenic |
| Disadvantages | Expensive, delicate, water spots, sun damage, requires careful handling in production |

### Linen

| Property | Value |
|----------|-------|
| Fiber Source | Flax plant (Linum usitatissimum) stem fibers |
| Common Weaves | Plain weave, twill, herringbone |
| Weight Range | 100-350 GSM (shirt 100-150, trouser 200-280, upholstery 280-350) |
| Typical Cost Range | $6.00-$20.00/yard |
| Shrinkage | 4-8% (significant first wash; pre-washing recommended) |
| Care | Machine wash warm, tumble dry low. Improves with washing. Wrinkles heavily. |
| Common Uses | Summer shirts, trousers, blazers, dresses, napkins, tablecloths |
| Advantages | Extremely breathable, absorbent, gets softer with wear, strong fiber, biodegradable |
| Disadvantages | Wrinkles significantly, less drape than cotton, limited color range, higher cost |

### Wool

| Property | Value |
|----------|-------|
| Fiber Source | Sheep (merino, lambswool, shetland) and other animals (cashmere, mohair, alpaca) |
| Common Weaves | Twill, plain weave, flannel, gabardine, jersey knit, crepe |
| Weight Range | 120-500 GSM (tropical 120-180, suiting 240-350, coating 400-500) |
| Typical Cost Range | $8.00-$25.00/yard (wool), $30.00-$80.00/yard (cashmere), $15.00-$40.00/yard (merino) |
| Shrinkage | 5-10% if not treated (superwash/machine washable wool: <3%) |
| Care | Dry clean or hand wash cold. Lay flat to dry. Prone to felting in hot water/agitation. |
| Common Uses | Suits, coats, sweaters, scarves, blankets, socks |
| Advantages | Excellent insulation, natural elasticity, moisture-wicking, wrinkle-resistant, flame-resistant |
| Disadvantages | Pilling, felting risk, moth damage, itchiness (lower grades), dry clean requirement |

## Synthetic Fibers

### Polyester

| Property | Value |
|----------|-------|
| Fiber Source | Petroleum-derived polymer (PET) |
| Common Weaves | Jersey, satin, chiffon, georgette, crepe, interlock, micro-fiber |
| Weight Range | 60-400 GSM (chiffon 60-80, blouse 80-130, suiting 200-280, fleece 200-350) |
| Typical Cost Range | $1.50-$6.00/yard (standard), $4.00-$12.00/yard (performance/recycled) |
| Shrinkage | <1% (highly stable) |
| Care | Machine wash warm, tumble dry low. Quick drying. Resistant to most chemicals. |
| Common Uses | Athletic wear, blouses, linings, workwear, outerwear, home textiles |
| Advantages | Durable, wrinkle-resistant, quick-drying, colorfast, low cost, easy care |
| Disadvantages | Not breathable, retains odor, petroleum-based, microplastic shedding, static-prone, pills |

### Nylon (Polyamide)

| Property | Value |
|----------|-------|
| Fiber Source | Petroleum-derived polymer (PA6 or PA66) |
| Common Weaves | Taffeta, ripstop, tricot, mesh, taslan |
| Weight Range | 30-250 GSM (lingerie 30-60, activewear 100-180, outerwear 150-250) |
| Typical Cost Range | $3.00-$10.00/yard |
| Shrinkage | <1% |
| Care | Machine wash cold, tumble dry low. Sensitive to heat. |
| Common Uses | Activewear, swimwear, lingerie, hosiery, outerwear, bags |
| Advantages | Extremely strong, elastic, lightweight, abrasion-resistant, smooth hand feel |
| Disadvantages | Not breathable, UV-degradable, petroleum-based, heat-sensitive, static-prone |

## Blended Fabrics

### Cotton/Polyester (Polycotton)

| Property | Value |
|----------|-------|
| Common Ratios | 65/35, 60/40, 50/50 (cotton/polyester) |
| Weight Range | 100-250 GSM |
| Typical Cost Range | $2.00-$5.00/yard |
| Shrinkage | 1-3% (less than pure cotton) |
| Advantages | Combines cotton comfort with polyester durability and wrinkle resistance. More affordable than pure cotton. |
| Disadvantages | Less breathable than pure cotton, can pill, compromise on both natural and synthetic strengths |
| Common Uses | Uniforms, workwear, casual shirts, bed sheets |

### Cotton/Spandex (Stretch Cotton)

| Property | Value |
|----------|-------|
| Common Ratios | 95/5, 97/3, 98/2 (cotton/spandex) |
| Weight Range | 150-300 GSM |
| Typical Cost Range | $3.00-$8.00/yard |
| Shrinkage | 3-5% (spandex component resists shrinkage but can degrade with heat) |
| Advantages | Cotton comfort with stretch recovery. Form-fitting without restriction. |
| Disadvantages | Spandex degrades with heat and chlorine. Higher cost than straight cotton. |
| Common Uses | Jeans (stretch denim), fitted t-shirts, leggings, activewear |

### Polyester/Spandex

| Property | Value |
|----------|-------|
| Common Ratios | 90/10, 85/15, 80/20 (polyester/spandex) |
| Weight Range | 150-300 GSM |
| Typical Cost Range | $3.00-$8.00/yard |
| Shrinkage | <1% |
| Advantages | High stretch and recovery, quick-drying, durable, colorfast |
| Disadvantages | Not breathable, retains odor, petroleum-based |
| Common Uses | Athletic wear, swimwear, compression garments, dance wear |

## Specialty Fabrics

### Denim

| Property | Value |
|----------|-------|
| Composition | Typically 100% cotton or cotton/elastane (98/2 or 99/1) |
| Weight Range | 4 oz-16 oz per square yard (lightweight: 4-8 oz, mid-weight: 8-12 oz, heavyweight: 12-16 oz) |
| Typical Cost Range | $3.00-$12.00/yard (standard), $10.00-$25.00/yard (premium selvedge) |
| Shrinkage | 3-5% (raw/unwashed), <2% (sanforized/pre-washed) |
| Common Uses | Jeans, jackets, skirts, bags, upholstery |
| Key Notes | Twill weave with warp-faced construction. Indigo dye fades with washing (feature, not defect). Selvedge denim woven on shuttle looms, narrower width (28-32 inches). |

### Chiffon

| Property | Value |
|----------|-------|
| Composition | Silk, polyester, or nylon |
| Weight Range | 15-50 GSM |
| Typical Cost Range | $2.00-$5.00/yard (polyester), $10.00-$25.00/yard (silk) |
| Shrinkage | 1-3% (silk), <1% (polyester) |
| Common Uses | Evening wear, scarves, overlays, bridal wear |
| Key Notes | Very sheer, slippery, difficult to cut and sew. Requires specialized handling in production. Higher SAM (labor time) due to handling difficulty. |

### Jersey Knit

| Property | Value |
|----------|-------|
| Composition | Cotton, polyester, rayon, or blends |
| Weight Range | 120-300 GSM (lightweight: 120-160, medium: 160-220, heavyweight: 220-300) |
| Typical Cost Range | $2.50-$8.00/yard |
| Shrinkage | 3-8% (cotton jersey), <2% (synthetic jersey) |
| Common Uses | T-shirts, dresses, underwear, casual wear |
| Key Notes | Single knit fabric with natural stretch in width. Curls at edges when cut (production consideration). Requires ballpoint/stretch needles for sewing. |

## Fabric Weight Conversion

```
GSM to oz/yd2: GSM * 0.03527 = oz/yd2
oz/yd2 to GSM: oz/yd2 * 28.35 = GSM

Common equivalents:
120 GSM = ~3.5 oz/yd2 (lightweight shirt)
180 GSM = ~5.3 oz/yd2 (standard t-shirt)
250 GSM = ~7.4 oz/yd2 (sweatshirt)
350 GSM = ~10.3 oz/yd2 (heavy fleece)
400 GSM = ~11.8 oz/yd2 (canvas)
```
