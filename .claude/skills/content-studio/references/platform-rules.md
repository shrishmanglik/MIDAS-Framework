# Platform Rules Reference

## What This Is
A comprehensive reference for platform-specific rules, limits, algorithm signals, and best practices. This is the source of truth for Content Studio agents when formatting, sizing, and optimizing content for each platform.

---

## LinkedIn

### Character Limits
| Element | Limit |
|---------|-------|
| Post (feed) | 3,000 characters |
| "See more" threshold | ~210 characters (first 2-3 lines visible) |
| Article title | 100 characters |
| Article body | ~40,000 characters (~5,000 words) |
| Comment | 1,250 characters |
| Company page update | 700 characters (truncated beyond this) |

### Media Specifications
| Media Type | Specification |
|-----------|---------------|
| Image (single) | 1200x627 (landscape) or 1200x1200 (square). JPG/PNG. Max 10MB. |
| Image (carousel) | 1080x1080 or 1080x1350 per slide. PDF upload. Max 100MB. |
| Video | 3s-10min. 1920x1080 recommended. MP4. Max 5GB. |
| Document/PDF | Up to 300 pages. Max 100MB. |

### Algorithm Signals (What LinkedIn Prioritizes)
1. **Dwell time** — how long people spend reading your post (long posts with value win)
2. **Early engagement** — comments and reactions in first 60-90 minutes
3. **Comments > Reactions** — a comment is worth ~10x a like in algorithm weight
4. **Native content** — posts without external links get more reach than link posts
5. **Creator mode features** — newsletters, live events, and articles get boosted in creator mode
6. **Consistency** — regular posting (3-5x/week) is rewarded over sporadic bursts
7. **Engagement response** — replying to comments on your own posts extends distribution

### Posting Best Practices
- **Best times:** Tuesday-Thursday, 7:30-8:30 AM or 12:00-1:00 PM (audience's timezone)
- **Frequency:** 3-5 posts per week. More is fine if quality holds.
- **Hashtags:** 3-5 targeted hashtags. Placed at the end. Each should have >1K followers.
- **Formatting:** Line break between every 1-2 sentences. Whitespace is critical for mobile.
- **Links:** If including a link, put it in the first comment (not the post body) to avoid reach penalty.
- **Engagement:** Reply to every comment within 2 hours of posting.

## X / Twitter

### Character Limits
| Element | Limit |
|---------|-------|
| Tweet | 280 characters |
| Display name | 50 characters |
| Bio | 160 characters |
| DM | 10,000 characters |
| Thread | No limit on number of tweets, but 3-15 is optimal |
| Link | Always counted as 23 characters regardless of actual URL length |

### Media Specifications
| Media Type | Specification |
|-----------|---------------|
| Image | 1200x675 (16:9) or 1200x1200 (1:1). JPG/PNG/GIF. Max 5MB. Up to 4 per tweet. |
| Video | 0.5s-140s (2min 20s). MP4. 1920x1200 max. Max 512MB. |
| GIF | Max 15MB (under 5MB recommended). |

### Algorithm Signals
1. **Bookmarks** — the highest-quality engagement signal on X. Bookmarked content is genuinely valued.
2. **Reply engagement** — conversations (back-and-forth replies) boost distribution
3. **Retweets (reposts)** — extend reach to new audiences
4. **Dwell time** — time spent viewing the tweet (threads earn more dwell time)
5. **Velocity** — engagement in the first 30-60 minutes shapes distribution
6. **Content type** — images and videos get more reach than text-only tweets
7. **Following** — content from people you regularly engage with gets priority

### Posting Best Practices
- **Best times:** Monday-Friday, 9:00 AM-12:00 PM ET (tech/business audience)
- **Frequency:** 1-5 tweets per day. Quality matters more than volume.
- **Hashtags:** 0-2 maximum. X hashtags are less important than LinkedIn's.
- **Threads:** Post all tweets in the thread at once (not spread over hours).
- **Quote tweets:** Always add substantive commentary. Empty quote tweets are low value.
- **Media:** Tweets with images get 2-3x more engagement. Use them.

## Blog / Website (SEO)

### Technical Requirements
| Element | Requirement |
|---------|------------|
| Title tag | 50-60 characters, keyword near front |
| Meta description | 155-160 characters, keyword + CTA |
| URL slug | Under 60 characters, hyphens, lowercase, keyword-rich |
| H1 | Exactly one per page, includes primary keyword |
| H2-H3 | Logical hierarchy, no skipped levels |
| Page speed | Under 3 seconds load time |
| Mobile | Fully responsive |
| SSL | HTTPS required |

### Content Requirements
| Element | Guideline |
|---------|-----------|
| Minimum word count | 800 words for ranking potential |
| Ideal length | 1,500-2,500 words for most informational queries |
| Paragraph length | 2-4 sentences max |
| Subheading frequency | Every 200-300 words |
| Internal links | 3-5 per article |
| External links | 2-5 to authoritative sources |
| Image frequency | At least 1 per 300-500 words |
| Image alt text | Descriptive, keyword-inclusive where natural |
| Schema markup | Article, TechArticle, HowTo, or FAQ as appropriate |

### SEO Algorithm Factors (Google)
1. **Content quality and comprehensiveness** — cover the topic thoroughly, answer related questions
2. **Search intent match** — your content format must match what Google shows for the query
3. **E-E-A-T** — Experience, Expertise, Authoritativeness, Trustworthiness
4. **Page experience** — Core Web Vitals, mobile-friendly, no intrusive interstitials
5. **Backlinks** — quality external links pointing to your content
6. **Freshness** — recently updated content ranks better for time-sensitive queries
7. **Internal linking** — proper internal link structure distributes page authority

## YouTube

### Video Specifications
| Element | Specification |
|---------|---------------|
| Resolution | 1080p minimum (1920x1080), 4K preferred (3840x2160) |
| Aspect ratio | 16:9 for standard, 9:16 for Shorts |
| Format | MP4 with H.264 codec |
| Frame rate | 24fps or 30fps standard, 60fps for fast motion |
| Max file size | 256GB or 12 hours |
| Max duration | 12 hours |

### Metadata Limits
| Element | Limit |
|---------|-------|
| Title | 100 characters (60 visible in search, 70 in suggestions) |
| Description | 5,000 characters (first 2-3 lines visible before "show more") |
| Tags | 500 characters total, 5-15 tags recommended |
| Thumbnail | 1280x720 pixels, under 2MB, JPG/PNG |
| Shorts | 15-60 seconds, 9:16 vertical, title under 40 visible chars |

### Algorithm Signals
1. **Click-through rate (CTR)** — thumbnail + title = your ad in the YouTube feed
2. **Watch time** — total minutes watched. Longer videos that hold attention win.
3. **Audience retention** — percentage of the video watched. Drops signal problems.
4. **Session watch time** — does your video lead to more YouTube watching? YouTube rewards this.
5. **Engagement velocity** — likes, comments, shares in the first 24-48 hours
6. **Subscriber notification engagement** — subscribers who watch from notification signal high value

### Best Practices
- **Thumbnails:** Custom, high-contrast, readable text, expressive faces. This is 50% of your CTR.
- **First 8 seconds:** The cold open determines whether viewers stay. Hook immediately.
- **Chapters:** Add timestamps in description for chapter markers. Improves experience and SEO.
- **End screens:** Use the last 20 seconds for subscribe CTA and next video suggestion.
- **Cards:** Add 2-3 info cards linking to related videos at relevant moments.
- **Description:** Front-load key info (links, summary) in first 2-3 lines. Full keywords after.
- **Posting time:** Weekday mornings (9-11 AM ET) or Sunday evenings for tech content.

## Email

### Technical Standards
| Element | Requirement |
|---------|------------|
| Subject line | Under 60 characters (mobile-safe), under 40 ideal |
| Preview text | 40-90 characters |
| Email width | 600px max for consistent rendering |
| CAN-SPAM | Sender identified, physical address, unsubscribe link |
| Authentication | SPF, DKIM, DMARC configured |
| Plain text | Required alongside HTML |

### Deliverability Rules
| Factor | Guideline |
|--------|-----------|
| Spam words | Avoid: free, guarantee, act now, limited time, congratulations, winner, click here |
| Image ratio | Keep images under 40% of total email content |
| Link density | Max 3-5 links per email (more triggers spam filters) |
| ALL CAPS | Never in subject line or body (spam signal) |
| Exclamation marks | Max 1 per email |
| Unsubscribe | Must be functional, one-click, within 10 business days |

### Best Sending Times
| Email Type | Best Time |
|-----------|-----------|
| Cold outreach | Tuesday-Thursday, 8:00-9:30 AM recipient's timezone |
| Newsletter | Consistent same day/time each week (Tuesday or Thursday morning) |
| Product updates | Tuesday-Wednesday, 10:00 AM-12:00 PM |
| Avoid | Friday after 2 PM, weekends, holidays |

## Cross-Platform Posting Rules

| Rule | Rationale |
|------|-----------|
| Never copy-paste the same content across platforms | Each platform has different audience expectations, formats, and algorithms |
| Primary platform first, then repurpose | Post the "main" version first, then adapt for secondary platforms over 3-7 days |
| Native content > external links | Every platform penalizes posts that drive users away to other platforms |
| Respect each platform's formatting norms | LinkedIn whitespace, X brevity, YouTube retention hooks — adapt the format, not just the word count |
| Track with UTM parameters | Every link shared on social gets: ?utm_source=platform&utm_medium=social&utm_campaign=name |
