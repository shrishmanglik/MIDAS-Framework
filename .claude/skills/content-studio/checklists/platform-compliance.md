# Platform Compliance Checklist

## Description
A pre-publish verification checklist ensuring content meets each platform's technical requirements, formatting rules, and policy guidelines. Used by the Content Distributor before publishing and by the Content Editor during review.

## How to Use
Select the relevant platform section. Complete every checkbox before publishing to that platform. Items marked (Blocker) will cause the content to fail, display incorrectly, or violate platform policy. Items marked (Best Practice) optimize performance.

---

## LinkedIn

### Post Formatting
- [ ] (Blocker) Total post length under 3,000 characters (absolute platform limit)
- [ ] (Best Practice) Ideal length: 300-1,300 characters for feed algorithm optimization
- [ ] (Blocker) First 210 characters work standalone (visible before "see more" button)
- [ ] (Best Practice) Line breaks between every 1-2 sentences for mobile readability
- [ ] (Best Practice) No more than 5 hashtags (algorithm may suppress posts with more)
- [ ] (Best Practice) Hashtags placed at the end of the post, not inline

### Article Formatting
- [ ] (Blocker) Article length: 800-5,000 words (LinkedIn's suggested range)
- [ ] (Best Practice) Ideal length: 1,000-2,000 words for engagement
- [ ] (Blocker) Title under 100 characters
- [ ] (Best Practice) Includes header image (1200x628 pixels)
- [ ] (Best Practice) Subheadings (H2) every 200-400 words

### Carousel Formatting
- [ ] (Blocker) PDF format for upload (unless using native document feature)
- [ ] (Best Practice) 8-12 slides optimal (enough depth without fatigue)
- [ ] (Best Practice) Max 40 words per slide (visual format, not text-heavy)
- [ ] (Blocker) Slide dimensions: 1080x1080 (square) or 1080x1350 (portrait)
- [ ] (Best Practice) First slide is a compelling cover that earns the swipe

### Media Specifications
- [ ] (Blocker) Image: 1200x627 minimum, 1200x1200 for square. Max 10MB. PNG or JPG.
- [ ] (Blocker) Video: 3 seconds to 10 minutes. Max 5GB. MP4 format. 16:9 or 1:1.
- [ ] (Best Practice) Native video preferred over YouTube links (algorithm favors native)

### Posting Timing
- [ ] (Best Practice) Tuesday-Thursday, 7:30-8:30 AM or 12:00-1:00 PM (audience's timezone)
- [ ] (Best Practice) Avoid weekends and Mondays (lower engagement)
- [ ] (Best Practice) Respond to comments within 1-2 hours of posting (signals engagement to algorithm)

### Policy
- [ ] (Blocker) No misleading or false claims
- [ ] (Blocker) No spam behavior (excessive posting, engagement pods, automation abuse)
- [ ] (Blocker) Respect copyright — no unattributed content from others
- [ ] (Blocker) No prohibited content (hate speech, harassment, adult content)
- [ ] (Best Practice) Disclose AI-generated content where platform requires or norms suggest

## X / Twitter

### Single Tweet Formatting
- [ ] (Blocker) Under 280 characters (absolute limit, no exceptions)
- [ ] (Best Practice) Under 240 characters (leaves room for engagement without truncation)
- [ ] (Best Practice) 0-2 hashtags maximum (X isn't LinkedIn — hashtags don't help much)
- [ ] (Best Practice) Links counted as 23 characters regardless of actual length

### Thread Formatting
- [ ] (Blocker) Each individual tweet under 280 characters
- [ ] (Best Practice) Thread length: 3-15 tweets (longer threads lose readers)
- [ ] (Best Practice) Tweet 1 (hook) works completely standalone — valuable even without the thread
- [ ] (Best Practice) No filler tweets (every tweet earns its place)
- [ ] (Best Practice) Final tweet includes CTA

### Media Specifications
- [ ] (Blocker) Image: max 5MB. PNG, JPG, GIF. Up to 4 images per tweet.
- [ ] (Blocker) Image dimensions: 1200x675 (16:9) for single image, 1200x1200 for gallery
- [ ] (Blocker) Video: max 512MB. MP4. 0.5s to 140s duration. 1920x1200 max resolution.
- [ ] (Blocker) GIF: max 15MB. Recommended under 5MB for fast loading.
- [ ] (Best Practice) Alt text added to all images (accessibility and SEO)

### Posting Timing
- [ ] (Best Practice) Monday-Friday, 9:00 AM-12:00 PM ET (peak tech/business audience)
- [ ] (Best Practice) Engagement peaks: Tuesday-Thursday, 10:00-11:00 AM
- [ ] (Best Practice) Threads perform best early morning (audience reads with coffee)

### Policy
- [ ] (Blocker) No platform manipulation (fake engagement, coordinated behavior)
- [ ] (Blocker) No impersonation or misleading identities
- [ ] (Blocker) No spam (excessive posting of same content, aggressive self-promotion)
- [ ] (Blocker) Respect copyright and fair use
- [ ] (Best Practice) Quote tweets with added commentary (not just "This" or empty amplification)

## Blog / Website

### Content Formatting
- [ ] (Blocker) One H1 tag (the title) — no duplicate H1s on the page
- [ ] (Blocker) Logical heading hierarchy (H1 > H2 > H3, no skipping levels)
- [ ] (Best Practice) Paragraphs: 2-4 sentences (mobile readability)
- [ ] (Best Practice) Subheadings every 200-300 words
- [ ] (Best Practice) Bullet lists for 3+ related items
- [ ] (Best Practice) Bold for key terms and important phrases

### Technical Requirements
- [ ] (Blocker) Page loads in under 3 seconds (test with PageSpeed Insights)
- [ ] (Blocker) Mobile responsive (test on phone viewport)
- [ ] (Blocker) No broken links (internal or external)
- [ ] (Blocker) SSL certificate active (HTTPS, not HTTP)
- [ ] (Best Practice) Canonical URL set correctly
- [ ] (Best Practice) Open Graph and Twitter Card meta tags configured
- [ ] (Best Practice) XML sitemap updated to include new page
- [ ] (Best Practice) Submitted to Google Search Console for indexing

### Image Requirements
- [ ] (Blocker) All images have alt text
- [ ] (Best Practice) Images compressed (under 200KB for web display)
- [ ] (Best Practice) Images use descriptive file names (not IMG_0042.png)
- [ ] (Best Practice) Featured image: 1200x630 for social sharing
- [ ] (Best Practice) Images lazy-loaded for page speed

## YouTube

### Video Specifications
- [ ] (Blocker) Video resolution: 1080p minimum (1920x1080), 4K preferred (3840x2160)
- [ ] (Blocker) Aspect ratio: 16:9 for standard video, 9:16 for Shorts
- [ ] (Blocker) File format: MP4 with H.264 codec
- [ ] (Blocker) Max file size: 256GB or 12 hours, whichever is less
- [ ] (Best Practice) Frame rate: 24fps or 30fps for standard, 60fps for fast-motion content

### Metadata
- [ ] (Blocker) Title: under 100 characters (under 60 recommended — truncation in search)
- [ ] (Blocker) Description: include key information in first 2-3 lines (visible before "show more")
- [ ] (Best Practice) Description: 200-500 words with timestamps, links, and keywords
- [ ] (Best Practice) Tags: 5-15 relevant tags (primary keyword first)
- [ ] (Best Practice) Thumbnail: 1280x720 pixels, under 2MB, JPG/PNG
- [ ] (Best Practice) Custom thumbnail (not auto-generated frame)
- [ ] (Best Practice) Chapters/timestamps in description (creates chapter markers)
- [ ] (Best Practice) End screen and cards configured

### Shorts Specifications
- [ ] (Blocker) Duration: 15-60 seconds
- [ ] (Blocker) Vertical format: 9:16 (1080x1920)
- [ ] (Best Practice) Hook in first 2 seconds
- [ ] (Best Practice) Title under 40 characters (Shorts titles display shorter)
- [ ] (Best Practice) Hashtag: #Shorts in title or description

## Email (Newsletter / Outreach)

### Technical Requirements
- [ ] (Blocker) Plain text version exists alongside HTML version
- [ ] (Blocker) Unsubscribe link present and functional (CAN-SPAM requirement)
- [ ] (Blocker) Sender address is authenticated (SPF, DKIM, DMARC)
- [ ] (Blocker) Physical mailing address or P.O. Box included (CAN-SPAM requirement)
- [ ] (Best Practice) Email renders correctly in: Gmail, Outlook, Apple Mail (test before send)

### Formatting
- [ ] (Blocker) Subject line under 60 characters (mobile truncation beyond this)
- [ ] (Best Practice) Subject line: 3-7 words, specific, not spammy
- [ ] (Best Practice) Preview text set (40-90 characters, complements subject)
- [ ] (Best Practice) Single-column layout for mobile compatibility
- [ ] (Best Practice) Links are blue and underlined (standard convention)
- [ ] (Best Practice) CTA button is large enough to tap on mobile (minimum 44x44 pixels)

### Deliverability
- [ ] (Blocker) No spam trigger words: "free," "guarantee," "act now," "limited time," "congratulations," "winner"
- [ ] (Best Practice) Image-to-text ratio below 40% images (high image ratio triggers spam filters)
- [ ] (Best Practice) No ALL CAPS in subject line
- [ ] (Best Practice) No excessive exclamation marks (max 1 per email)
- [ ] (Best Practice) Links go to legitimate, SSL-secured domains

### Timing
- [ ] (Best Practice) Cold outreach: Tuesday-Thursday, 8:00-9:30 AM recipient's timezone
- [ ] (Best Practice) Newsletter: consistent day and time each week (habit formation)
- [ ] (Best Practice) Avoid Fridays after 2 PM and weekends
- [ ] (Best Practice) Avoid holidays and major industry events (inbox competition)
