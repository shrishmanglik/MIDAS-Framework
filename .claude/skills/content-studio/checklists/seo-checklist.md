# SEO Checklist

## Description
A comprehensive SEO quality check for any content intended to rank in search engines. Used by the SEO Optimizer during Phase 4 (Edit) and by Blog Writer during self-review. Covers on-page SEO, technical elements, content optimization, and post-publish tasks.

## How to Use
Complete all applicable sections before publishing search-targeted content. Items marked (Critical) must be completed — skipping them significantly impacts ranking potential. Items marked (Recommended) improve performance but won't block publishing.

---

## 1. Keyword Targeting

- [ ] (Critical) Primary keyword identified and validated (has search volume, achievable difficulty)
- [ ] (Critical) Search intent matches content format (informational intent = guide/tutorial, commercial = comparison/review, transactional = product page)
- [ ] (Recommended) 3-5 secondary keywords identified (related terms, synonyms, long-tail variations)
- [ ] (Recommended) No keyword cannibalization — this page targets a unique keyword not already targeted by another page on the site
- [ ] (Recommended) Long-tail variations naturally incorporated throughout the content

## 2. Title Tag

- [ ] (Critical) Primary keyword present, ideally near the beginning
- [ ] (Critical) Length: 50-60 characters (check that it won't be truncated in SERP)
- [ ] (Critical) Compelling for humans — this is both an SEO element and a click-through-rate driver
- [ ] (Recommended) Includes a power word or number (e.g., "50x," "Complete Guide," "Step-by-Step")
- [ ] (Recommended) Unique — no other page on the site has the same title tag

## 3. Meta Description

- [ ] (Critical) Primary keyword included naturally
- [ ] (Critical) Length: 155-160 characters (truncation loses the message)
- [ ] (Critical) Contains a compelling reason to click (not just a summary — a value proposition)
- [ ] (Recommended) Includes a call to action (implicit or explicit)
- [ ] (Recommended) Unique — no duplicate meta descriptions across the site

## 4. URL / Slug

- [ ] (Critical) Primary keyword present in the URL slug
- [ ] (Critical) Short and readable (under 60 characters for the slug portion)
- [ ] (Critical) Uses hyphens, not underscores or spaces
- [ ] (Critical) Lowercase only — no mixed case
- [ ] (Recommended) No unnecessary words (remove "a," "the," "and," "of" unless they're part of the keyword)
- [ ] (Recommended) No dates in the URL (enables content refreshes without URL changes)

## 5. Heading Structure

- [ ] (Critical) Exactly one H1 tag on the page (the article title)
- [ ] (Critical) H1 includes the primary keyword
- [ ] (Critical) H2 headings for major sections (3-7 per article)
- [ ] (Critical) Heading hierarchy is logical — no H3 without a parent H2, no H4 without a parent H3
- [ ] (Recommended) At least one H2 includes a secondary keyword naturally
- [ ] (Recommended) H2s are descriptive enough to serve as a table of contents (scannable)
- [ ] (Recommended) H3s used for subsections where complexity warrants it

## 6. Content Body Optimization

- [ ] (Critical) Primary keyword appears in the first 100 words
- [ ] (Critical) Primary keyword density: 0.5-2% (natural, not forced)
- [ ] (Critical) Content length is competitive with top-ranking results for this keyword
- [ ] (Critical) Content provides comprehensive coverage — no obvious gaps compared to top 5 SERP results
- [ ] (Recommended) Secondary keywords distributed naturally throughout sections
- [ ] (Recommended) Related questions answered (People Also Ask, FAQ schema candidates)
- [ ] (Recommended) Synonyms and semantic variations used (natural language, not just keyword repetition)
- [ ] (Recommended) Data points, statistics, and evidence included (signals authority)

## 7. Internal Linking

- [ ] (Critical) 3-5 internal links to related pages on the site
- [ ] (Critical) Anchor text is keyword-rich and descriptive (not "click here" or "read more")
- [ ] (Recommended) Links to authoritative internal pages (cornerstone content, pillar pages)
- [ ] (Recommended) Links placed contextually within relevant paragraphs (not just a "Related" section at the bottom)
- [ ] (Recommended) Identify 3-5 existing pages that should link BACK to this new content

## 8. External Linking

- [ ] (Recommended) 2-5 external links to authoritative sources (supports claims, adds credibility)
- [ ] (Recommended) External links open in new tabs (keeps readers on your site)
- [ ] (Recommended) External links are to high-authority domains (not spammy or irrelevant sites)
- [ ] (Recommended) No broken external links (check at publish time)

## 9. Images and Media

- [ ] (Critical) All images have descriptive alt text (include keyword where natural)
- [ ] (Critical) Image file names are descriptive (not IMG_0042.png but ai-saas-architecture-diagram.png)
- [ ] (Recommended) Images are compressed for fast loading (under 200KB for web images)
- [ ] (Recommended) At least one image per 300-500 words (visual breakup improves engagement)
- [ ] (Recommended) Featured/hero image is compelling (drives click-through from social shares)
- [ ] (Recommended) Image dimensions are consistent and don't cause layout shift

## 10. Schema Markup

- [ ] (Recommended) Appropriate schema type added (Article, TechArticle, HowTo, FAQ, Product)
- [ ] (Recommended) Schema is valid JSON-LD format
- [ ] (Recommended) Schema includes: headline, description, author, datePublished, publisher
- [ ] (Recommended) If FAQ content exists, FAQ schema is implemented (enables rich results)
- [ ] (Recommended) Schema validated with Google's Rich Results Test tool

## 11. Readability

- [ ] (Critical) Paragraphs are 2-4 sentences max (mobile readability)
- [ ] (Critical) Subheadings appear every 200-300 words (prevents wall-of-text)
- [ ] (Recommended) Flesch-Kincaid grade: 8-10 for general content, up to 12 for technical
- [ ] (Recommended) Average sentence length: 15-20 words
- [ ] (Recommended) Passive voice under 10% of sentences
- [ ] (Recommended) Bullet lists used for 3+ related items (scannable)
- [ ] (Recommended) Bold used for key terms (helps skimmers)

## 12. Technical SEO Elements

- [ ] (Critical) Page loads in under 3 seconds
- [ ] (Critical) Page is mobile-responsive (test on phone viewport)
- [ ] (Critical) No duplicate content issues (canonical tag set if needed)
- [ ] (Recommended) Open Graph tags set (og:title, og:description, og:image)
- [ ] (Recommended) Twitter Card tags set (twitter:title, twitter:description, twitter:image)
- [ ] (Recommended) Breadcrumb navigation present and has schema markup
- [ ] (Recommended) Page is included in XML sitemap
- [ ] (Recommended) No noindex tag (unless intentionally excluded from search)

## 13. Post-Publish Tasks

- [ ] (Critical) Submit URL to Google Search Console for indexing
- [ ] (Recommended) Verify page appears in sitemap
- [ ] (Recommended) Check Google's mobile-friendly test
- [ ] (Recommended) Validate schema with Rich Results Test
- [ ] (Recommended) Set calendar reminder for 30-day ranking check
- [ ] (Recommended) Set calendar reminder for 90-day content refresh evaluation

## Quick Reference: Character Limits

| Element | Limit | Display Truncation |
|---------|-------|--------------------|
| Title tag | 50-60 chars | Truncated with "..." at 60 |
| Meta description | 155-160 chars | Truncated at 160 |
| URL slug | Under 60 chars | Long slugs look bad but aren't truncated |
| H1 | No hard limit | Should match title tag intent |
| Image alt text | Under 125 chars | Screen readers may truncate longer |
