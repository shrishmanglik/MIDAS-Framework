# X Single Tweet Template

## Description
A fill-in-the-blank template for single tweets (max 280 characters). The most constrained content format — every character counts. Designed for maximum impact in minimum space.

## When to Use
- Sharing a single sharp insight, opinion, or observation
- Promoting content with a compelling one-liner plus link
- Engaging in conversations with quote-tweets or replies
- Testing ideas that might become threads or longer content later

## Template Structures

### Structure A: Insight Tweet
```
{OBSERVATION — a sharp, specific insight that makes people nod or think}

{IMPLICATION — why this matters, in one sentence}
```

### Structure B: Contrarian Tweet
```
{CONVENTIONAL_WISDOM — what most people believe} (setup)

{CONTRARIAN_TAKE — why that's wrong or incomplete}

{EVIDENCE — one proof point}
```

### Structure C: Stat + Takeaway
```
{STRIKING_STATISTIC}

{CONTEXT — what makes this stat meaningful}

{TAKEAWAY — what to do about it}
```

### Structure D: Before/After
```
{BEFORE — what it used to be or what most people do}

{AFTER — what it is now or what you do differently}

{RESULT — the difference it made}
```

### Structure E: Promotion Tweet (with link)
```
{HOOK — why someone should click}

{VALUE_PROMISE — what they'll get}

{LINK}
```

## Variable Definitions

| Variable | Description | Constraints |
|----------|-------------|-------------|
| `{OBSERVATION}` | A specific, sharp insight | Max 140 characters |
| `{IMPLICATION}` | Why it matters | Max 120 characters |
| `{CONVENTIONAL_WISDOM}` | What people assume | Max 80 characters |
| `{CONTRARIAN_TAKE}` | Why they're wrong | Max 100 characters |
| `{EVIDENCE}` | One proof point | Max 80 characters |
| `{STRIKING_STATISTIC}` | A number that surprises | Max 80 characters |
| `{CONTEXT}` | What the stat means | Max 100 characters |
| `{TAKEAWAY}` | What to do about it | Max 80 characters |
| `{HOOK}` | Why to click | Max 100 characters |
| `{VALUE_PROMISE}` | What they'll get | Max 100 characters |
| `{LINK}` | URL | Standard URL length |

## Rules
- Total tweet MUST be under 280 characters. Non-negotiable.
- Write 3 versions of every tweet. Pick the sharpest one.
- If you can remove a word without losing meaning, remove it.
- "That," "very," "really," "just," and "actually" can almost always be deleted.
- Links count as 23 characters regardless of actual URL length.
- No hashtags on single tweets unless absolutely necessary (max 1).
- Media (image, video) can accompany the tweet — note direction if needed.

## Completed Examples

### Insight Tweet
```
The best AI products are 95% not-AI.

Math, rules, and caching do the heavy lifting. The LLM is the final 5%.

That's not a limitation. That's the moat.
```
(248 characters)

### Contrarian Tweet
```
Everyone says "use AI for everything."

We built 95% of our app without a single API call.

Result: 50x cheaper. More accurate. Harder to copy.
```
(148 characters)

### Stat + Takeaway Tweet
```
$0.003 vs $0.15 per AI reading.

Same output quality. Same user experience.

The difference? We made 95% of the computation deterministic. No AI needed for math.
```
(164 characters)

### Before/After Tweet
```
Before: Send everything to GPT-4. $1,500/day at scale.

After: Swiss Ephemeris for math, rule engine for logic, cache for patterns. AI for the last 5%.

$30/day. Same results.
```
(176 characters)

### Promotion Tweet
```
I wrote the full architecture breakdown for building AI products that are 50x cheaper to run.

3-tier framework. Real cost numbers. Step-by-step implementation guide.

[link]
```
(177 characters + link)
