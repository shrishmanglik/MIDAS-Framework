# LinkedIn Post Template

## Description
A fill-in-the-blank template for creating LinkedIn feed posts. Designed to work WITHOUT AI generation for standard use cases. Covers the four most effective LinkedIn post structures.

## When to Use
- Sharing a professional insight, lesson, or opinion on LinkedIn
- Promoting content, products, or services to a professional audience
- Building thought leadership through consistent posting
- When you need a post quickly and a Tier 1 template is faster than AI generation

## Template Structures

### Structure A: Story > Lesson > CTA

```
{HOOK_LINE_1}
{HOOK_LINE_2}

{STORY_SETUP — 1-2 sentences establishing the situation}

{STORY_CONFLICT — what went wrong, what was surprising, what changed}

{STORY_RESOLUTION — what happened as a result}

{LESSON_BRIDGE — "Here's what I learned:" or "The takeaway:"}

{LESSON_1}
{LESSON_2}
{LESSON_3}

{CTA — single clear ask}

{HASHTAG_1} {HASHTAG_2} {HASHTAG_3}
```

### Structure B: Problem > Agitation > Solution > CTA

```
{HOOK_LINE_1}
{HOOK_LINE_2}

{PROBLEM_STATEMENT — describe the pain point your audience faces}

{AGITATION — why this problem is worse than they think, what it costs them}

{SOLUTION_BRIDGE — "Here's how we solved it:" or "There's a better way:"}

{SOLUTION_STEP_1}

{SOLUTION_STEP_2}

{SOLUTION_STEP_3}

{RESULT — what the outcome was, with numbers if possible}

{CTA}

{HASHTAG_1} {HASHTAG_2} {HASHTAG_3}
```

### Structure C: Hot Take > Evidence > Nuance > CTA

```
{CONTRARIAN_HOOK — bold statement that challenges conventional wisdom}

{EVIDENCE_1 — why you believe this}

{EVIDENCE_2 — data point or example supporting your claim}

{EVIDENCE_3 — another supporting point}

{NUANCE — "Now, this doesn't mean..." or "The caveat:" — show you've thought it through}

{CONCLUSION — restate the take with the nuance included}

{CTA}

{HASHTAG_1} {HASHTAG_2} {HASHTAG_3}
```

### Structure D: List of Insights > Framing > CTA

```
{HOOK — "X things I learned about {TOPIC} after {EXPERIENCE}:"}

1. {INSIGHT_1}
{BRIEF_EXPLANATION_1}

2. {INSIGHT_2}
{BRIEF_EXPLANATION_2}

3. {INSIGHT_3}
{BRIEF_EXPLANATION_3}

4. {INSIGHT_4}
{BRIEF_EXPLANATION_4}

5. {INSIGHT_5}
{BRIEF_EXPLANATION_5}

{FRAMING — why these matter, what the reader should do with this information}

{CTA}

{HASHTAG_1} {HASHTAG_2} {HASHTAG_3}
```

## Variable Definitions

| Variable | Description | Constraints |
|----------|-------------|-------------|
| `{HOOK_LINE_1}` | First line of the hook — must work standalone before "see more" | Max 100 characters |
| `{HOOK_LINE_2}` | Second line of the hook — visible before "see more" | Max 110 characters (combined with line 1 must be under 210 chars) |
| `{STORY_SETUP}` | Set the scene for the story | 1-2 sentences |
| `{STORY_CONFLICT}` | The turning point or surprise | 1-3 sentences |
| `{STORY_RESOLUTION}` | What happened as a result | 1-2 sentences |
| `{LESSON_BRIDGE}` | Transition phrase from story to takeaway | 5-10 words |
| `{LESSON_1-3}` | Key takeaways | 1 sentence each |
| `{PROBLEM_STATEMENT}` | The audience's pain point | 1-2 sentences |
| `{AGITATION}` | Why the problem is costly | 1-3 sentences |
| `{SOLUTION_STEP_1-3}` | Steps in the solution | 1-2 sentences each |
| `{RESULT}` | Quantified outcome | 1-2 sentences with numbers |
| `{CONTRARIAN_HOOK}` | Bold opening statement | 1-2 sentences max |
| `{EVIDENCE_1-3}` | Supporting points | 1-2 sentences each |
| `{NUANCE}` | The "but also" that shows depth | 1-2 sentences |
| `{CTA}` | Single call to action | 1-2 sentences, ONE ask only |
| `{HASHTAG_1-3}` | Relevant hashtags | 3-5 hashtags, each >1K followers |
