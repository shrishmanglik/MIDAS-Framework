# X Thread Template

## Description
A fill-in-the-blank template for X (Twitter) threads. Threads allow in-depth content on a platform built for brevity. The key is making every tweet valuable standalone while maintaining narrative momentum across the full thread.

## When to Use
- Breaking down a complex topic into digestible pieces
- Sharing a story, case study, or behind-the-scenes narrative
- Presenting a list of insights, tips, or lessons learned
- When the topic needs more than 280 characters but the audience is on X

## Template Structure (7-12 Tweets)

```
TWEET 1 — THE HOOK
{HOOK_STATEMENT — bold claim, surprising stat, or intriguing premise}
{THREAD_PROMISE — what the reader will learn}
[thread indicator: a colon, "Here's how:", or similar]

TWEET 2 — CONTEXT
{BACKGROUND — set the stage, establish credibility or stakes}
{TRANSITION — bridge to the first main point}

TWEET 3 — POINT 1
{POINT_1 — first key insight, lesson, or story beat}
{EVIDENCE_1 — supporting detail, number, or example}

TWEET 4 — POINT 2
{POINT_2}
{EVIDENCE_2}

TWEET 5 — POINT 3
{POINT_3}
{EVIDENCE_3}

TWEET 6 — POINT 4
{POINT_4}
{EVIDENCE_4}

TWEET 7 — POINT 5
{POINT_5}
{EVIDENCE_5}

TWEET 8 — THE INSIGHT (Pattern Break)
{KEY_INSIGHT — the "aha" that reframes everything above}
{WHY_IT_MATTERS — one sentence on implications}

TWEET 9 — CLOSER + CTA
{SUMMARY — 1-2 sentences wrapping up the thread}
{CTA — follow, bookmark, reply, link — pick ONE}
```

## Variable Definitions

| Variable | Description | Constraints |
|----------|-------------|-------------|
| `{HOOK_STATEMENT}` | The opening line that stops the scroll | Max 200 characters (leave room for thread promise) |
| `{THREAD_PROMISE}` | What the reader will gain from the thread | Max 60 characters |
| `{BACKGROUND}` | Context that establishes the story or credibility | Max 230 characters |
| `{TRANSITION}` | Bridge sentence to the content | Max 50 characters |
| `{POINT_1-5}` | Main content points | Max 180 characters each |
| `{EVIDENCE_1-5}` | Supporting details | Max 100 characters each |
| `{KEY_INSIGHT}` | The central aha moment | Max 200 characters |
| `{WHY_IT_MATTERS}` | One-sentence implication | Max 80 characters |
| `{SUMMARY}` | Thread wrap-up | Max 140 characters |
| `{CTA}` | Single call to action | Max 100 characters |

## Rules
- EVERY tweet must be under 280 characters. No exceptions. Count before finalizing.
- Tweet 1 must work completely standalone. If someone only sees tweet 1, they got value.
- No filler tweets. If a tweet can be deleted without breaking the thread, delete it.
- End each tweet (except the last) with tension that pulls to the next.
- Max 1-2 hashtags in the entire thread (in the last tweet only).
- No "1/" numbering unless the hook tweet is strong enough without it.
- Include media direction for at least one tweet (screenshot, diagram, or image).

Generate once. Serve to the next 1,000 users.

Cost: ~$0.001 per hit. Handles 20%.

Step 4: AI handles ONLY the final personalized narrative.

The part that's genuinely unique to this specific user's complete chart. About 5% of total computation.

Cost: ~$0.05.
