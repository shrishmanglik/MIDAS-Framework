# Monitoring Setup Workflow

## Steps
1. **SLO Definition** — SRE Analyst defines SLOs with stakeholders
2. **Instrumentation** — Design metrics and logging
3. **Alerting** — Create actionable alert rules
4. **Dashboards** — Design monitoring dashboards
5. **Runbooks** — Create incident response runbooks
6. **Review** — DevOps Reviewer validates (ALWAYS subagent)
7. **Delivery** — Complete observability package
