# Infrastructure Setup Workflow

## Steps
1. **Requirements** — DevOps Director gathers infrastructure needs
2. **Architecture** — Infrastructure Engineer designs (subagent)
3. **Security Review** — Route to security-studio
4. **Implementation** — Write IaC configurations
5. **Review** — DevOps Reviewer validates (ALWAYS subagent)
6. **Delivery** — Infrastructure specs ready for provisioning
