# Cicd Pipeline Setup Workflow

## Steps
1. **Requirements** — Define build, test, deploy needs
2. **Pipeline Design** — CI/CD Specialist creates pipeline
3. **Container Config** — Container Specialist creates Dockerfiles
4. **Monitoring** — SRE Analyst adds monitoring hooks
5. **Review** — DevOps Reviewer validates (ALWAYS subagent)
6. **Delivery** — Pipeline configs ready for implementation
