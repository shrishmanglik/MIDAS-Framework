# Prohibited Language

## Never Use
- "Leverage" (use: use, apply)
- "Synergy" (use: collaboration, combined effect)
- "Disrupt" (use: transform, improve)
- "Revolutionary" (use: significant, meaningful)
- "Best-in-class" (use: specific measurable claim)
- "Cutting-edge" (use: current, modern)
- "Game-changer" (use: specific impact description)

## Always Avoid
- Jargon without explanation
- Superlatives without evidence
- Passive voice in CTAs
- Gendered language (use: they/them defaults)
- Ableist language (use: inclusive alternatives)
