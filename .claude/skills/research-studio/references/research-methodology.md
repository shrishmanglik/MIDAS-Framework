# Research Methodology Guide

## Primary vs Secondary Research

### Primary Research (Original data)
- **Interviews:** 1-on-1 conversations with target users/experts. Best for "why" questions.
- **Surveys:** Structured questionnaires at scale. Best for "how many" questions.
- **Observation:** Watching users interact with products. Best for behavior vs stated preference gaps.
- **A/B Testing:** Controlled experiments. Best for "which performs better" questions.

### Secondary Research (Existing data)
- **Industry reports:** Gartner, Forrester, McKinsey, CB Insights. Expensive but comprehensive.
- **Government data:** Census, BLS, SEC filings. Free, authoritative, but lagging.
- **Academic papers:** Peer-reviewed research. Rigorous but narrow scope.
- **Public company filings:** 10-K, 10-Q, S-1. Best for market sizing triangulation.
- **News/press releases:** Current events. Useful for trend signals, unreliable for data.

## Qualitative vs Quantitative

| Aspect | Qualitative | Quantitative |
|--------|------------|--------------|
| Question type | "Why?" "How?" | "How many?" "How much?" |
| Sample size | 5-30 participants | 100+ respondents |
| Output | Themes, patterns, quotes | Numbers, statistics, charts |
| Strength | Depth, nuance, discovery | Generalizability, precision |
| Weakness | Not generalizable | Misses context and nuance |
| Best for | Exploration, hypothesis generation | Validation, measurement |

## Method Selection Matrix

| Research Question | Recommended Method | Minimum Viable |
|------------------|--------------------|----------------|
| Market size | Secondary + bottom-up calc | 2 industry reports + triangulation |
| User needs | Interviews + JTBD | 8 interviews minimum |
| Competitor analysis | Secondary + product review | 3 competitors, public data |
| Tech evaluation | Hands-on + community review | Scoring matrix with 5+ criteria |
| Pricing | Competitor benchmarking + Van Westendorp | 3 competitor price points |
| Trend analysis | Secondary + expert interviews | 3 independent sources agreeing |
