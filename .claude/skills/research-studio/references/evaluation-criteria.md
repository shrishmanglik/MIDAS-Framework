# Standard Evaluation Criteria

## Technology Evaluation Dimensions
| Criterion | What It Measures | Scoring Guide |
|-----------|-----------------|---------------|
| Performance | Speed, throughput, latency | Benchmarks vs alternatives |
| Scalability | Growth handling capacity | Architecture limits, scaling patterns |
| Ecosystem | Libraries, plugins, integrations | Package count, quality of top packages |
| Community | Support, Stack Overflow presence | GitHub stars, monthly downloads, response time |
| Documentation | Quality, completeness, examples | Coverage, up-to-date, runnable examples |
| Learning Curve | Time to productive use | Days to first feature, complexity gradient |
| Maturity | Production readiness, stability | Version number, years in production, known users |
| Security | Vulnerability history, security features | CVE count, security audit history |
| Maintainability | Long-term maintenance burden | Breaking change frequency, migration tooling |
| Cost | Licensing, infrastructure, talent | License type, hosting costs, developer salary premium |

## Market Analysis Dimensions
| Criterion | What It Measures |
|-----------|-----------------|
| Market Size | TAM/SAM/SOM in revenue |
| Growth Rate | CAGR over 3-5 years |
| Competition | Number and strength of competitors |
| Barriers to Entry | Capital, technology, regulatory, network effects |
| Customer Concentration | Revenue dependency on top customers |
| Regulatory Risk | Government intervention likelihood |
| Technology Risk | Disruption likelihood from new tech |

## Competitor Evaluation Dimensions
| Criterion | What It Measures |
|-----------|-----------------|
| Product Quality | Feature depth and user experience |
| Market Position | Brand recognition, market share |
| Pricing | Price point relative to value delivered |
| Growth Trajectory | Funding, hiring, product releases |
| Moat Strength | Defensibility of competitive advantage |
| Vulnerability | Known weaknesses to exploit |

## Scoring Guide (1-10)
- **1-2:** Critical weakness, major risk
- **3-4:** Below average, significant gaps
- **5-6:** Average, meets minimum requirements
- **7-8:** Above average, clear strength
- **9-10:** Exceptional, industry-leading
