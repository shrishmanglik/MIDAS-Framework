## Source Evaluation Criteria

Before using any data point, evaluate it against these criteria:

| Criterion | Question to Ask | Red Flag |
|-----------|----------------|----------|
| **Recency** | When was this data collected? | More than 12 months old |
| **Source** | Who published this and why? | Marketing material disguised as research |
| **Methodology** | How was the data collected? | Methodology not disclosed |
| **Sample Size** | How many data points? | Very small sample or unrepresentative |
| **Bias** | Does the publisher benefit from a particular conclusion? | Vendor publishing data about their own market |
| **Corroboration** | Do other independent sources agree? | Single source with no corroboration |
| **Specificity** | Is the data specific enough for our question? | Global data when we need regional |
