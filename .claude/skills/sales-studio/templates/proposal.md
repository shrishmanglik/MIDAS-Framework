# Proposal Template

> Use this template for all client-facing proposals. Customize every section to the specific client. Never submit a generic proposal.

---

## Instructions

1. Replace all `[BRACKETED]` placeholders with client-specific content
2. Delete any sections that do not apply (but think twice before deleting -- most sections exist for a reason)
3. Every proposal must lead with the client's problem, not our features
4. Pricing must appear AFTER the value proposition, never before
5. The executive summary must be readable as a standalone document

---

## Proposal Quality Checklist

Before sending any proposal, verify:

- [ ] Client name and details are correct throughout (search and verify)
- [ ] Executive summary works as a standalone document
- [ ] Client's problem is stated in their own language
- [ ] Solution section leads with client outcomes, not our features
- [ ] Scope has explicit inclusions AND exclusions
- [ ] Every deliverable has acceptance criteria or a milestone
- [ ] Timeline is realistic with client review points built in
- [ ] Pricing appears after value is established
- [ ] ROI or value justification is quantified
- [ ] "Why Us" section has specific evidence, not generic claims
- [ ] At least 1 relevant case study is included
- [ ] Next steps are clear, specific, and actionable
- [ ] Terms cover payment, IP, confidentiality, and cancellation
- [ ] Disclaimer is included (not legal advice)
- [ ] Document is free of grammatical errors and formatting issues
- [ ] Proposal has been read from the client's perspective
