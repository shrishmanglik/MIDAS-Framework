# WCAG 2.1 AA Quick Reference

## Level A (Minimum)
- Alt text for images
- Keyboard accessible
- No keyboard traps
- Page titled
- Focus order logical
- Link purpose clear

## Level AA (Target)
- Contrast 4.5:1 normal, 3:1 large
- Text resizable to 200%
- Multiple ways to find pages
- Consistent navigation
- Consistent identification
- Error suggestion
- Error prevention (legal/financial)

## Testing Tools
- axe DevTools (automated)
- Lighthouse (automated)
- VoiceOver/NVDA (manual screen reader)
- Keyboard-only navigation (manual)
