# MDS Design Principles

## 1. Clarity Over Cleverness
Every element must communicate its purpose immediately.

## 2. Consistency Is Kindness
Consistent patterns reduce cognitive load.

## 3. Accessible By Default
Accessibility is not an afterthought.

## 4. Content First
Design serves content, not the other way around.

## 5. Progressive Disclosure
Show what is needed when it is needed.

## 6. Responsive Is Responsible
Every screen size deserves a good experience.
