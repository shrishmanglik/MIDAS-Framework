# Typography Guide

## Type Scale (1.25 ratio)
- xs: 12px / 0.75rem
- sm: 14px / 0.875rem
- base: 16px / 1rem
- lg: 20px / 1.25rem
- xl: 25px / 1.563rem
- 2xl: 31px / 1.953rem
- 3xl: 39px / 2.441rem

## Line Height
- Headings: 1.2-1.3
- Body: 1.5-1.6
- UI labels: 1.2

## Font Pairing Rules
- Pair serif heading with sans-serif body
- Maximum 2 font families per project
- Use weight variation within a family for hierarchy
