# Color Theory Reference

## Contrast Ratios (WCAG)
- Normal text: 4.5:1 minimum
- Large text (18px+): 3:1 minimum
- UI components: 3:1 minimum

## Color Harmony
- Complementary: opposite on wheel (high contrast)
- Analogous: adjacent on wheel (harmonious)
- Triadic: equidistant on wheel (vibrant)

## Semantic Colors
- Red/Orange: error, danger, destructive
- Green: success, positive, growth
- Yellow/Amber: warning, caution
- Blue: information, trust, primary action
- Gray: neutral, disabled, secondary
