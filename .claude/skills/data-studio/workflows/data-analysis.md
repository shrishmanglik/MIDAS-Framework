# Data Analysis Workflow

## Steps
1. **Define** — Data Director clarifies the question
2. **Query** — Data Analyst writes and runs queries
3. **Analyze** — Statistical analysis and pattern identification
4. **Visualize** — Visualization Specialist designs charts
5. **Review** — Data Reviewer validates (ALWAYS subagent)
6. **Deliver** — Report with methodology
