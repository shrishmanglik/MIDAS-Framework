# Etl Pipeline Workflow

## Steps
1. **Requirements** — Data Director defines pipeline needs
2. **Architecture** — Data Engineer designs pipeline (subagent)
3. **Quality** — Data Analyst defines validation rules
4. **Review** — Data Reviewer validates design (ALWAYS subagent)
5. **Deliver** — Pipeline specification with monitoring plan
