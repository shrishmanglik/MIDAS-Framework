# Dashboard Design Workflow

## Steps
1. **Requirements** — Data Director gathers stakeholder needs
2. **Data Audit** — Data Analyst verifies data availability
3. **Design** — Visualization Specialist creates dashboard spec
4. **Pipeline** — Data Engineer ensures data freshness (subagent)
5. **Review** — Data Reviewer validates accuracy (ALWAYS subagent)
6. **Deliver** — Dashboard specification for implementation
