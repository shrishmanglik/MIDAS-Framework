# Security Documentation Workflow

## Steps
1. **Requirements** — Security Director defines documentation needs
2. **Draft** — Security Documenter creates documents
3. **Technical Review** — AppSec Analyst validates technical accuracy
4. **Review** — Security Reviewer validates completeness (ALWAYS subagent)
5. **Legal Review** — Route to legal-studio if needed
6. **Deliver** — Approved security documentation
