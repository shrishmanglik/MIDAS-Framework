# Threat Modeling Workflow

## Steps
1. **Scope** — Security Director defines assessment boundaries
2. **Architecture Review** — Gather system architecture and data flows
3. **Threat Model** — Threat Modeler builds STRIDE model (subagent)
4. **Risk Scoring** — Score and prioritize threats
5. **Mitigation Planning** — AppSec Analyst recommends mitigations
6. **Review** — Security Reviewer validates (ALWAYS subagent)
7. **Deliver** — Threat model with prioritized mitigations
