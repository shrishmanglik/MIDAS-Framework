# Security Review Workflow

## Steps
1. **Scope** — Define review scope and focus areas
2. **Code Review** — AppSec Analyst reviews code for vulnerabilities
3. **Architecture Review** — Check security architecture patterns
4. **Dependency Scan** — Check for known vulnerable dependencies
5. **Review** — Security Reviewer validates findings (ALWAYS subagent)
6. **Deliver** — Security report with remediation priorities
