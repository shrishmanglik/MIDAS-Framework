# Active Projects Registry

## Format
Each active project should be tracked with:

| Field | Description |
|-------|------------|
| Project ID | Unique identifier |
| Name | Project name |
| Lead Studio | Primary studio responsible |
| Supporting Studios | Other studios involved |
| Phase | Current pipeline phase |
| Status | Active / Paused / Blocked / Complete |
| Started | Start date |
| Last Activity | Last update date |
