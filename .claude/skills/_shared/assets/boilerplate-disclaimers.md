# MDS Boilerplate Disclaimers

## Universal Disclaimer (ALL deliverables)

```
This content was generated by AI (Million Dollar AI Studio).
All outputs should be reviewed by qualified professionals before
implementation or publication.
```

## Domain-Specific Disclaimers

### Legal Studio

```
LEGAL DISCLAIMER: This document is generated by AI and does NOT
constitute legal advice. It is provided for informational and
educational purposes only. No attorney-client relationship is
created by this content. Consult a licensed attorney in your
jurisdiction before making any legal decisions or taking legal action.
```

**Required on:** All contracts, compliance analyses, legal memos, policy documents, IP assessments.

## Placement Rules

| Deliverable Type | Placement |
|-----------------|-----------|
| Documents & reports | Footer of first page + metadata |
| Code & configs | Header comment block |
| Presentations | Final slide |
| Email/message drafts | Footer text |
| API responses | Response metadata field |
| Templates | Pre-populated in output section |

## Stacking Rules

When a deliverable spans multiple domains, **stack all applicable disclaimers** in order:
1. Universal disclaimer (always first)
2. Primary domain disclaimer
3. Secondary domain disclaimers (alphabetical)

Example: A healthcare marketing campaign would include:
1. Universal disclaimer
2. Healthcare disclaimer
3. Advertising disclaimer
