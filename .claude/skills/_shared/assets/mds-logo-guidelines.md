# MDS Logo Guidelines

## Primary Logo

**Million Dollar AI Studio** (full name) or **MDS** (abbreviated)

### Usage Rules

| Context | Format |
|---------|--------|
| Documents & reports | "Million Dollar AI Studio" (first mention), "MDS" (subsequent) |
| CLI output headers | `[MDS]` prefix |
| Agent signatures | `— {Agent Name}, {Studio}` |
| Deliverable footers | `Generated by MDS {studio-name}` |

## Typography

| Element | Style |
|---------|-------|
| Studio names | lowercase-hyphenated: `dev-studio`, `content-studio` |
| Agent names | Title Case: `Systems Architect`, `Brand Strategist` |
| Framework name | Always: `MIDAS` (all caps) |
| Full brand | Always: `Million Dollar AI Studio` (title case) |

## Attribution Format

### Deliverable Attribution
```
---
Generated by: MDS {studio-name}
Agent: {agent-name}
Date: {YYYY-MM-DD}
Quality Gate: {passed/pending}
---
```

### Cross-Studio Handoff Attribution
```
---
Source Studio: {originating-studio}
Target Studio: {receiving-studio}
Handoff Type: {deliverable type}
Generated: {YYYY-MM-DD}
---
```

## Prohibited Usage

- Never abbreviate as "MDAS" or "M.D.S."
- Never use "Million $" — always spell out "Dollar"
- Never represent MDS as a human entity — always identify as AI
- Never remove attribution from generated deliverables
- Never use agent names without their studio context

## Co-Branding

When MDS produces deliverables for a client:
- Client brand takes primary position
- MDS attribution appears in metadata/footer only
- Never let MDS branding overshadow client identity
