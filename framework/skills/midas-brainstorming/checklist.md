# Brainstorming gate checklist

Deterministic gates distilled from midas-brainstorming. Each box is a fact
about the spec record on disk, checkable by a session with no other context.

- [ ] Project files, recent commits, and open work orders were read before the first question
- [ ] The interrogation set (5-7 request-specific questions) was run and answered from evidence
- [ ] At least one interrogation answer changed the plan, or the questions were replaced with better ones
- [ ] Two or three approaches with trade-offs were presented, recommendation first
- [ ] The spec was presented in chunks with a verdict recorded per chunk
- [ ] The spec contains zero placeholders ("TBD", "handle errors appropriately"), verified by literal search
- [ ] Assumptions surviving into the spec are listed with the evidence that would confirm or kill each
- [ ] Rejected approaches are recorded with one line of reasoning each
- [ ] No implementation artifact (code, scaffolding, config) was created before spec approval
- [ ] The requester's explicit approval of the full spec is on record
